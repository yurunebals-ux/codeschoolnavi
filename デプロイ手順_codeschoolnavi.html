公開までの手順｜codeschoolnavi.com

プログラミングスクール比較サイト ・ ■あなた=要ログイン/購入 ・ ■私=代行可能
全体像:GitHubにコードを置く → Cloudflare Pagesが自動でサイトを公開 → GitHub Actionsが毎日AIで記事を生成・追加 → Pagesが自動で再公開。サーバー費0円で無人運転になります。

STEP 0. ドメイン取得

■あなた（購入が必要）
1
codeschoolnavi.com を取得（Cloudflare Registrar 推奨・約¥1,500/年）。CloudflareならDNSも自動で楽です。

STEP 1. GitHubにコードを置く

■あなた=アカウント作成 / ■私=アップロード代行可
1
GitHub の無料アカウントを作成（または既存でOK）。
2
新しいリポジトリ（例 codeschoolnavi）を作成。
3
納品したzipの中身をアップロード（ログイン後の画面で私が代行できます）。

STEP 2. Cloudflare Pagesで公開

■あなた=アカウント作成 / ■私=設定代行可
1
Cloudflare → Workers & Pages → Pages → GitHubリポジトリを接続。
2
ビルド設定を以下の通りに入力:
項目値
Framework presetAstro
Root directory（重要）site
Build commandnpm install && npm run build
Build output directorydist
3
環境変数に SITE_URL=https://codeschoolnavi.com と SITE_NAME を追加。

STEP 3. 独自ドメインを接続

■あなた=承認 / ■私=設定代行可
1
Pagesプロジェクト → Custom domains → codeschoolnavi.com を追加。CloudflareでDNSも取得済みなら自動設定されます。

STEP 4. 毎日の自動記事生成をON

■あなた=APIキー入力 / ■私=設定代行可
1
GitHubリポジトリ → Settings → Secrets and variables → Actions に登録: LLM_API_KEY（AIのAPIキー）、SITE_URL、SITE_NAME、INDEXNOW_KEY（生成済み: a77cf03e731e2c8ffbef06cf3fd92398）。
2
これで .github/workflows/daily.yml が毎日自動で記事を生成・公開します。

STEP 5. ASPにサイト登録 → 提携 → リンク反映

■あなた=ログインのみ / ■私=登録〜提携〜リンク反映まで代行
1
公開された codeschoolnavi.com を もしも・A8 にメディア（サイト）登録。
2
私が全対象校へ提携申請→承認後に広告リンク取得→affiliates.jsonへ反映。もしもの高単価CPA（RUNTEQ¥7,000／インターノウス¥14,000 等）が有効化されます。
あなたが実際にやるのは: ①ドメイン購入 ②GitHub/Cloudflareアカウント作成＆ログイン ③AIのAPIキー用意 ④各ASPにログイン。
それ以外（アップロード・ビルド設定・ドメイン接続・提携申請・リンク反映）は、ログイン済み画面で私が代行できます。
