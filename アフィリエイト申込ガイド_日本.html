アフィリエイト申込ガイド（日本ASP版）

プログラミングスクール比較サイト向け ・ 登録はすべて無料 ・ 所要 約40〜60分
順番が重要: 日本のASPは登録時（またはプログラム提携時）にあなたのサイトURLを審査します。 まず ①ドメイン取得 → ②システムをデプロイして記事を数本公開・広告表記ページを設置 → ③下の各ASPに登録 → ④スクール案件と提携申請、の順が通りやすいです。 A8.net はサイト審査なしで即登録できるので最初に。次に案件が豊富な afb・アクセストレード・もしも へ。
⚠ ステマ規制（必須）: 2023年10月以降、広告には「広告」「PR」等の明瞭な表記が義務です。 本システムは全記事の冒頭とフッターに【広告】表記を自動付与済み。表記のない記事は品質ゲートが自動で公開を止めます。

登録〜案件提携の手順（各ASP共通）

1
上のURLから「無料会員登録」。メール認証 → 基本情報とサイトURLを入力。
2
報酬の振込先口座を登録（ゆうちょ等）。
3
管理画面で「プログラミングスクール」を検索し、data/affiliates.json に載っている各スクール（テックキャンプ / DMM WEBCAMP / TechAcademy / RUNTEQ / 侍エンジニア / Aidemy 等）と提携申請。
4
提携承認後、各案件の広告リンク（計測URL）を取得。
5
data/affiliates.json の各スクールの affiliate_url（現在 REPLACE-...）を取得したリンクに置き換えて保存 → git push。
